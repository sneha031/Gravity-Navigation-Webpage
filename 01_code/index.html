Gravity Aided Navigation in GNSS Denied Environments

A simulation-based research project investigating how gravity maps can support inertial navigation when GNSS is unavailable.

Project Overview

This project simulates an aircraft moving through the Patterson Lake gravity field and evaluates several gravity-aided navigation approaches. The code models INS drift, generates simulated gravity measurements, applies TERCOM map matching using Free Air gravity and vertical gravity-gradient information, implements OMSL-ICCP gravity matching, and evaluates A* route-planning strategies designed to improve gravity-aided positioning performance.

## Simulation of Gravity Data for GPS Denied Navigation Webpage

The purpose of this webpage is to provide a simple visual overview of the research on Gravity Aided Navigation in GNSS denied environments.

The webpage gives a short description of the research and displays two animations created from the simulation. The goal is to make the main idea and results of the project easy to view without needing to access or run the full research code.

## Webpage Content

The webpage includes:

- A short overview of the Gravity Aided Navigation research
- TERCOM Gravity Aided Navigation animation
- OMSL-ICCP with A* Route Planning animation
- A link to download the final research report


## Animations

The first animation shows the simulated aircraft navigation using:

- True aircraft path
- INS only path
- Free Air TERCOM
- Free Air & Vertical Gravity Gradient TERCOM

The second animation shows the OMSL-ICCP navigation results for four different A* route-planning approaches:

- Route A - Shortest A*
- Route B - PCRB Gravity-Aware A*
- Route C - OMSL-Aware A*
- Route D - Sequence-Aware A*

## Purpose

This webpage is separate from the main research code repository. It is designed only to present a short description of the research, the main simulation animations, and the final report through a simple public webpage.
